# FT-20261111-06: 외부 하중과 손목 잔차의 평가 기준 분리

- 상태: CLOSED
- 검증 범위: 소프트웨어·저장 원본 검증, 새 하드웨어 실험은 미실행
- 분류: CONTACT/DATA/OPS
- 누가: 기존 모델·TCN-GRU·Phys-MLP 비교 실험 운용자
- 언제: 2026-11-11, 외부 약 3 N 접촉 결과 검토 후
- 어디서: `comparison.py`, `comparison_gui.py`, `session_20261111_05`
- 무엇을: 외부 약 3 N 목표를 손목 잔차 3 N 검출 경계처럼 해석할 소지가 있었고,
  기존 ramp 집계는 외부 접촉 전에 발생한 첫 CONTACT도 검출 힘으로 저장했다.
- 왜: 외부 하중 구간과 observer 출력을 대조하는 분석이 없고 최초 전환만 집계했다.
- 어떻게: `test_ramp_first_edge_before_external_contact_is_not_a_detection`에서 외부
  하중 0 N의 사전 CONTACT를 재현했고 기존 구현이 이를 검출 힘 0 N으로 기록했다.

## 수정

- 외부 ON/OFF 1.6/1.0 N과 손목 잔차 3.0/1.2 N은 기존 값을 유지한다.
  GUI에서 별도 표시하고 외부 약 3 N 목표가 잔차 경계가 아님을 명시한다.
- `ExternalLoadReference`를 GUI·offline 분석이 공유한다. 끊긴 입력은 UNKNOWN이며
  fresh low-force hold 전에는 FREE로 확정하지 않는다.
- 공통 유효·동기 sample의 외부 하중 기준 상대 precision/recall과 구간별
  검출·사전 활성·검출/해제 지연을 보고한다. 미검출 지연은 null이며 조기 해제는
  음수로 기록한다. 미확정 합격값이나 정식 CO-04 승인은 만들지 않는다.
- ramp는 첫 외부 하중 구간의 상한 도달 전 새 전환만 검출 힘으로 집계한다.
  검출 직전의 실제 힘 상승률을 남기고 조건 이탈 자료는 clean ramp 집계에서 뺀다.
- 사용자가 기존 weak2~5를 혼합 하중으로 보존·분리하고 weak9회를 보충하도록
  선택했다. 명시적 제외 목록은 현재 세션에 기록하며 기존 trial metadata와
  raw bag은 변경하지 않는다. 이후 파일당 외부 접촉 1구간과 약한 접촉의 연속
  20 ms >5 N 여부로 계획 횟수를 판정하며 **모델 미검출로 제외하지 않는다.**

## 검증과 한계

- 관련 Python 테스트 65개, 패키지 전체 Python 130개·C++ 6개 통과.
- 임시 디렉터리에서 기존 weak1 원본을 실제 세 모델로 다시 계산했다.
  외부 접촉 1구간, 외부 최대 3.977 N, `plan_eligible=true`였고 세 모델의
  최종 안내 유지 2초 CONTACT 비율은 모두 0이었다. 미검출이어도 자료를 유지했다.
- 실제 예비 기록 cache로 GUI 표시와 clean weak1 / 남은 weak9·normal10·ramp10을
  확인한다. cache preview는 새 물리 실험이나 새로운 runtime evidence가 아니다.
- 초기 회귀 검사에서 세 항목이 실패한 뒤 수정했다. 추가 검증에서 NumPy bool의
  JSON 직렬화 결함을 찾아 Python bool로 저장하고 직렬화 회귀 검사를 추가했다.
- 최초 원본 재분석 명령은 workspace overlay source 누락으로 URDF 패키지를
  찾지 못했다. 세 ROS 환경을 모두 source한 뒤 통과했다.
- 문제 문서의 상태 행에 설명을 덧붙여 문서 하네스 형식 검사가 한 번 실패했다.
  상태는 단독 행으로, 검증 범위는 별도 행으로 분리했다.
- 임시 GUI 검증 스크립트는 압축 cache를 반복 해제해 지연돼 중단했다. 한 번만
  메모리에 읽도록 수정했다. 또한 예비 기록의 상태를 FREE라고 가정한 assertion이
  실패해 실제 cache 상태와 화면이 같은지 검증하도록 수정했다.
- 실제 세션의 긴 노이즈 설명을 표시할 때 마지막 모델 행이 잘려 표 높이를
  확보하고 세 모델의 모든 현재값·판정이 보이는지 확인했다.
- 외부 기준 지연은 262.5 Hz sample·hold·pairing 영향을 포함한다. 정확한 최초
  물리 접촉 시각·절대 힘 교정·실시간 추론/제어 지연을 검증한 것이 아니다.
- 로봇 이동·zero-set·새 수집·teleoperation·feedback 활성화는 실행하지 않았다.
