## Detector 후보 재생

확실한 FREE episode의 false activation을 0으로 만드는 최소 후보는
`2.5 N / 40 ms` 또는 `3.0 N / 20 ms`였다. 과거 102개 IL episode에 저장된
pseudo-label과의 재생 비교는 다음과 같다.

| ON / CONTACT hold | precision | recall | event precision | event recall | false activation | onset p95 |
|---|---:|---:|---:|---:|---:|---:|
| 2.5 N / 12 ms, 변경 전 | 88.84% | 67.93% | 83.67% | 95.19% | 274 | 37.73 ms |
| 2.5 N / 40 ms | 94.28% | 66.05% | 95.27% | 94.23% | 181 | 225.02 ms |
| 3.0 N / 20 ms | 93.86% | 65.91% | 95.81% | 94.23% | 190 | 217.06 ms |

두 후보 모두 pseudo-label onset 지연을 크게 늘리고 residual p95/p99/max를
낮추지는 못한다. 운용자 결정으로 더 짧은 hold에서 같은 pseudo-label event recall을
보인 `3.0 N / 20 ms`를 임시 선택했다. 독립 contact ground truth 전에는 이 값을
`CO-04` 승인값으로 간주하지 않는다.
