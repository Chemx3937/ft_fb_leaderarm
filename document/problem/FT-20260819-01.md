## 2026-08-19 residual 후속 분석

- task 3개는 모두 final13 train에 포함됐고 max/p95/RMSE는
  `3.903/1.303/0.743 N`이었다. 이는 in-sample이라 일반화 evidence가 아니다.
- diverse validation 3개는 `3.980/1.687/0.951 N`, 이미 공개된 test 3개는
  `6.260/1.460/0.857 N`이었다.
- episode 평균 residual norm은 `0.050~0.616 N`이었지만, 평균 residual을 완벽히
  제거하는 oracle도 전체 p95를 `1.436 → 1.357 N`만 낮추고 max는 낮추지 못했다.
  상수 offset은 전체 force squared error의 약 `11.9%`였다.
- 정지에 가까운 구간의 max/p95/RMSE는 `2.360/1.014/0.581 N`, 이동 구간은
  `6.260/1.492/0.865 N`이었다. 속도와 가속도 사분위가 증가할수록 p95가 단조롭게
  증가했다.
- `div08` 최대 오차 시 acceleration norm은 `9.059 rad/s²`였고 test 최대값은
  train 최대 `8.399 rad/s²`를 넘는 `15.664 rad/s²`였다. 새 동적 상태의 범위
  부족이 일부 기여하지만, train 범위 안인 `div01`도 max `2.691 N`이어서 유일한
  원인은 아니다.
- validation에서 `-16~+16 samples` global lag를 탐색해도 RMSE 개선은
  `0.9511 → 0.9499 N`뿐이고 max는 악화되어 단순 timestamp shift 가설은
  지지되지 않았다.

판정은 상수 offset/drift만의 문제가 아니라 동적 구간 residual과 상태 범위 문제가
더 크게 남아 있다는 것이다. warm-up/zero 절차는 유지한다. causal acceleration
smoothing과 짧은 history의 validation 평가는 아래 후속 실험에서 완료했다. 상세
지표 해석과 task/diverse 표는
[수집 실험 기록](../experiment/free_space_wrench_dataset_collection.md#평가지표-의미와-해석-방법)에
기록했다.

### sync, payload·중력, target 반복성 분리

Sync 관찰:

- 선택 모델 prediction을 사후 +2 samples, 약 7.6 ms 이동하면 max/RMSE가
  `3.201/0.788 → 2.890/0.753 N`으로 낮아졌다.
- 그러나 같은 정렬을 causal feature로 다시 학습한 lag-2 후보는 max가
  `3.539 N`으로 악화됐다. short-history 후보의 최적 lag는 0이고 dynamic MLP는
  +2에서 RMSE만 소폭 개선되며 max는 `3.884 → 3.936 N`으로 악화됐다.
- force error와 절대 sync error의 상관은 `0.039`였다. 공통 timestamp shift가
  최대오차의 주원인이라는 가설은 지지되지 않는다.

Payload·중력과 동적 항 관찰:

- controller 설정의 `use_ft_payload_gravity_comp`는 `false`다. `payload_id`는
  dataset 혼합 방지 식별자이며 실제 중력 보정을 설정하지 않는다.
- 자세만 쓰는 static gravity baseline max는 `5.971 N`이다. 선택 모델도 가장 낮은
  acceleration 사분위에서 max/p95 `2.198/0.975 N`, 가장 높은 사분위에서
  `3.109/1.655 N`이었다. 동적 항이 오차를 키우지만 quasi-static 구간도 max gate를
  통과하지 못한다.
- validation group별 상수 residual을 oracle로 제거해도 max는
  `3.201 → 3.087 N`만 감소했다. tare offset만으로 최대오차를 설명할 수 없다.

Target 반복성 관찰:

- 고정 manifest 16개 독립 tare의 같은 zero pose force median은 Fz에서
  `-0.565~+0.810 N`, peak-to-peak `1.375 N`, tare 간 STD `0.356 N`이었다.
- validation의 1초 이상 정지·관절변위 `<=0.2 deg`인 3구간에서 median 대비 force
  norm p95는 `0.551~0.591 N`, max는 `0.830~0.895 N`이었다.
- 이전 장기 정지 실험의 순간 max `1.327 N`, 독립 tare Fz peak-to-peak
  `1.31 N`과도 일관된다. target noise와 tare 반복성이 `1 N` max 예산의 상당 부분을
  차지하지만, group-offset oracle 결과상 현재 `3.201 N` 전체 실패의 유일한 원인은
  아니다.

판정은 체크포인트의 `max >= 3 N` 분기다. 같은 방식의 동작 episode 수집은 중단한다.
다음 단계는 실제 payload 질량·질량중심, sensor/tool transform과 cable 조건을 다시
확인하고, train만으로 물리 중력 baseline을 평가하며, 독립 정지 반복 evidence로
`1 N max` target-noise 한계를 별도로 판단하는 것이다. 합격 기준은 evidence 없이
완화하지 않는다.
