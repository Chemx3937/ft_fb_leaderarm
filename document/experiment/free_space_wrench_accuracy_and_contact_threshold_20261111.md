# 세 모델의 무접촉 예측 성능, FT drift와 3 N 접촉 기준 해석

2026-11-11 KST 대화에서 확인한 수치와 해석을 기록한다. 저장된 실험 결과와
기존 운용 계약을 검토한 기록이며, 새 실험이나 모델·detector 승인 기록은 아니다.

현재 관측한 무접촉 조건에서 **3 N·20 ms는 오접촉 판정을 줄이기 위한 잠정
기준으로 합리적**이다. 다만 과거 Fz drift `2.41 N`보다 크다는 이유만으로
장시간 안정성이나 실제 `3 N` 접촉의 검출을 보장할 수는 없다.

## 세 모델의 무접촉 예측 성능

독립 zero-set 4개에서 각각 60초씩 5회, 총 20회·1,200초를 평가했다.
세 모델의 공통 유효 표본은 `315,000개`, 무효·재준비 표본은 `0개`다.
오차는 sensor frame의 힘 3축에 대해 다음처럼 정의한다.

```text
e_force(t) = ||F_sensor(t) - F_free_prediction(t)||_2
vector RMSE = sqrt(mean(e_force(t)^2))
```

`F_sensor`는 hardware zero가 적용된 출력이며 손목 software bias를 추가로
제거하지 않았다. 다음 표는 토크를 포함한 6축 전체의 정확도 판정이 아니다.

| 모델 | RMSE [N] | p95 [N] | p99 [N] | 최대 [N] | false CONTACT [회] |
|---|---:|---:|---:|---:|---:|
| 기존 모델 (`baseline_current`) | 0.782044 | 1.247257 | 1.570639 | 3.333091 | 0 |
| TCN-GRU | 0.791918 | 1.283559 | 1.636524 | 3.160366 | 0 |
| Phys-MLP | 0.812512 | 1.313595 | 1.658719 | 3.391099 | 0 |

기존 모델의 RMSE와 p99가 가장 작다. TCN-GRU와 Phys-MLP의 RMSE는 기존 대비
각각 약 `1.26%`, `3.90%` 높다. zero-set별 순위가 달라 이번 기술 통계만으로
모든 작업에서의 우열이나 통계적 유의성을 확정하지 않는다.

이번 세션에서 선택된 20회의 저장 예측 배열로 RMSE·p95·p99·최대를 재계산했고
집계값과 일치했다. 집계에 기록된 artifact SHA-256 60개도 일치했다.

원본 집계와 분석 결과는 다음 경로에 있다.

- `data/three_model_comparison/free_twenty_trial_report.md`
- `data/three_model_comparison/free_twenty_trial_summary.json`
- `data/three_model_comparison/free_twenty_zero_metrics.csv`
- `data/three_model_comparison/free_twenty_phase_metrics.csv`

두 번째 zero-set의 선택 기록 4개는 사전 정지 검사가 없고 사후 정지 측정으로
보완했다. 제어 지연 원인도 해결되지 않았다. 입력 유효성이나 offline 표본 수를
live 추론·제어 주기 정상의 근거로 해석하지 않는다. 관련 경위는
[FT-20261111-01](../problem/FT-20261111-01.md)을 따른다.

## 장시간 유지했을 때의 2.41 N 변화

2026-08-18에는 이미 켜져 있던 오른팔 FT를 기준 자세에서 zero-set한 뒤,
같은 tare를 유지하고 120분 동안 이동 명령 없이 측정했다. tool·payload·hand·
cable 배치를 유지했고 시작·종료 관절 차이는 최대 약 `0.04 deg`였다.

Fz 중앙값은 `+0.22 → -2.19 N`으로 변했다. **2.41 N은 시작 대비 Fz 중심의
변화량**이며, 순간 노이즈 피크·3축 잔차 상한·교정된 절대 오차를 뜻하지 않는다.
force median의 3축 변화는 `[+0.63,+0.06,-2.41] N`이고, 120분 시점 median
벡터의 크기는 `2.271 N`이었다.

축별 STD는 전 구간 `0.40 N` 이내였으나 60분·120분에서 영점 검사를 실패했다.
노이즈 증가보다 중심값 drift가 문제였다. 이 실험은 live stream 통계만 남고
raw 파일은 보존하지 못했다.
[post-zero 120분 실험 기록](aft_post_zero_drift_and_tare_repeatability.md)

별도의 2026-08-18~19 cold-start 실험에서는 Fz 중앙값이
`+0.30 → +0.64 → +1.00 → +0.01 → -0.73 N`으로 변했고, 시작 대비 120분
변화는 `-1.03 N`이었다. 단조 감소가 그대로 재현되지는 않았다. 실제 전원 ON
시각은 따로 기록하지 못했고, 측정은 driver 시작 약 10분 뒤부터라 초기
0~10분 변화는 포함하지 않는다.
[cold-start 실험 기록](aft_cold_start_warmup_drift.md)

첫 실험 종료 후 같은 조건에서 zero-set을 10회 반복했을 때 Fz 중앙값의 회차 간
peak-to-peak는 `1.31 N`, STD는 `0.482 N`이었다. 영점 검사 통과가 tare 간
동일한 중심값을 보장하지는 않았다.

이 결과는 로봇에 장착된 상태의 측정계에서 관측한 drift다. 센서 내부만의 결함이나
온도만의 영향으로 확정하지 않았고, cable strain·장착 응력·구조 하중·controller의
기여도는 분리하지 못했다. 과거의 `2.41 N`이 현재 20회 평가에서도 발생했다거나,
항상 그 이내로 제한된다는 뜻도 아니다.

## 센서 공식 사양과 실제 운용 노이즈

사용 중인 오른팔 센서는 AIDIN ROBOTICS `AFT200-D80-C`다.
[공식 CAN 매뉴얼](https://help.aidinrobotics.co.kr/6%EC%B6%95-%ED%9E%98/%ED%86%A0%ED%81%AC-%EC%84%BC%EC%84%9C-can)의
사양과 운용 권고는 다음과 같다.

| 항목 | 공식 값 |
|---|---:|
| 힘 분해능 | 0.15 N |
| 힘 Noise-free resolution (STD) | 0.4 N |
| 토크 분해능 | 0.015 Nm |
| 토크 Noise-free resolution (STD) | 0.025 Nm |
| 최대 sample rate | 1,000 Hz |
| warm-up 권고 | 사용 전 최소 10분, 안정화 약 30분 |

분해능·STD·절대 정확도는 서로 다른 값이다. `STD 0.4 N`을 최대 오차
`±0.4 N`으로 해석하지 않는다. 확인한 공식 사양표에는 절대 정확도·비선형성·
히스테리시스의 오차 수치가 없어 개별 교정성적서나 기준 하중 검증이 필요하다.
제조사의 warm-up 권고만으로 이번 측정계의 장시간 안정성이 검증되는 것은 아니다.

최근 네 zero-set의 손목 정지 측정은 다음 범위였다.

| 실측 항목 | 범위 |
|---|---:|
| Fx STD | 0.115~0.120 N |
| Fy STD | 0.168~0.178 N |
| Fz STD | 0.180~0.257 N |
| 중앙값 제거 force norm p99 | 0.599~0.722 N |
| 중앙값 제거 force norm 최대 | 0.862~1.029 N |

근거는 `data/three_model_comparison/free_twenty_sensor_noise.csv`다.
이는 센서·장착·제어기가 포함된 운용 상태의 정지 변동이며 센서 단독 노이즈를
분리한 실험은 아니다. 외부 기준용 센서의 통계와 손목 통계를 섞지 않는다.

축별 분산의 합으로 계산한 정지 force vector의 평균 주변 RMS는 약
`0.27~0.33 N`이다. 모델 잔차 RMSE `0.78~0.81 N`과 비교하면 현재 오차 전체를
정지 노이즈만으로 설명하기는 어렵다. 다만 정지와 동작 조건이 달라 이 차이를
순수 모델 오차로 단정하거나 두 값을 단순히 빼서 오차 예산을 계산하지 않는다.
기존 사양·rate 설명은 [AFT sensor 문서](../AFT_sensor_issue.md)를 따른다.

## 3 N 접촉 기준의 근거와 해석

현재 [observer 설정](../../config/observer.yaml)은 ON/OFF `3.0/1.2 N`,
CONTACT/FREE hold `20/20 ms`다.
[SchmittContactDetector](../../ft_fb_leaderarm/contract.py)는 FREE 상태에서
force residual norm이 `3.0 N 이상`인 상태가 관측 시각 기준 `20 ms 이상`
이어지면 CONTACT로 전환한다. CONTACT에서는 `1.2 N 이하`가 `20 ms 이상`
이어져야 FREE로 복귀하며 중간 구간에서는 기존 상태를 유지한다.

이 값은 과거 `2.41 N` drift에 여유를 더해 산출한 값이 아니다.
2026-09-01 무접촉 task 2개의 offline replay에서 false CONTACT를 0으로 만든
후보 중 운용자가 `3.0 N / 20 ms`를 임시 선택했다.
[당시 후보 비교와 선택 기록](../problem/FT-20260901-01.md)

11월 11일의 20회 비교에서도 세 모델 모두 false CONTACT가 `0회·0초`였다.
순간 잔차는 3 N을 넘었지만 연속 초과 구간의 첫~마지막 관측 표본 간격은 최대
약 `3.81 ms`로 CONTACT hold보다 짧았다. 이 결과는 현재 관측한 무접촉 조건에서
잠정 설정의 오검출 억제 근거를 보완한다.

대화에서 말한 “3 N 목표”는 다음 세 가지를 구분한다.

| 목표 | 현재 근거로 가능한 판단 |
|---|---|
| 무접촉 잔차를 대체로 3 N 이내로 유지 | 시험한 조건에서는 기존 모델 p99 1.571 N이고 오접촉 0회 |
| 무접촉 최대 잔차를 항상 3 N 이하로 보장 | 기존 모델 최대 3.333 N이므로 충족하지 못함 |
| 실제 접촉력 3 N을 확실히 검출 | 잔차 문턱과 실제 힘은 다르므로 별도 접촉 검증 필요 |

센서 영점 drift가 모델 예측에서 보상되지 않으면 잔차에 남는다. 여기에 동작 중
예측 오차가 더해지거나 서로 상쇄될 수 있으므로 `3 - 2.41 = 0.59 N`을 검증된
여유로 간주하지 않는다. 이번 20분은 zero-set 4개로 나뉜 평가여서 같은 zero를
유지한 120분 운용의 오검출 안정성도 보장하지 않는다.

기존 `FS-06` 기준인 p95 `<=1.2 N`, p99 `<=1.5 N`, hard max `<=2.5 N`과
비교하면 세 모델 모두 잔차 조건을 충족하지 못한다. 오접촉 0회만으로 `FS-06`을
PASS 처리하거나 독립 접촉 검증 `CO-04`를 승인하지 않는다.
[합격 기준](../../docs/acceptance-contract.md)

남은 확인은 같은 zero를 유지한 장시간 무접촉 평가, 독립 접촉 정답을 사용한
미검출·검출/해제 지연 평가, 기존 데이터에서 영점 편차·시간 drift·동작 오차를
구분하는 분석이다. 새 하드웨어 평가는 별도 사용자 승인 아래 수행한다.

이번 기록 작업은 설명 문서와 안내 링크에만 영향을 준다. 모델, detector 설정,
승인 상태와 로봇 제어 코드는 변경하지 않았고 로봇 이동·zero-set·추가 데이터
수집·teleoperation·feedback 실행도 하지 않았다.
